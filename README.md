# BookLovers

BookLovers is a responsive website built using HTML and Tailwind CSS. It is designed to provide a clean, user-friendly experience for browsing book categories, featured books, and contacting the team.

## Features

- **About** – Introduction to the purpose of the site.
- **Categories** – Explore different types of books.
- **Featured Books** – Highlighted selections for users.
- **Contact** – A simple way for users to get in touch.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)

## Responsive Design

The layout is fully responsive and adjusts to desktop, tablet, and mobile screens using Tailwind CSS's utility classes.
